# Contributing

Thank you for helping improve the Product Manager Interview skill.

## Useful contributions

- Add or improve Product Manager case studies.
- Improve the assessment criteria or follow-up probing.
- Test the instructions with Codex, Claude, Gemini, Kimi, or another assistant.
- Report unclear guidance, broken links, or provider-specific issues.
- Improve the quick-start documentation.

## Privacy

Do not submit real CVs, résumés, interview notes, contact details, or other personal information in issues, pull requests, discussions, examples, or test fixtures. Use fictional or redacted examples.

## Pull requests

Please explain:

1. What you changed.
2. Why the change improves interview preparation.
3. Which provider or role level you tested, if applicable.
4. Any limitations or follow-up work.

Please keep changes focused and update the relevant documentation when behaviour or setup changes.
