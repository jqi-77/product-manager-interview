# Product Manager Interview

A generic, structured Product Manager interview practice skill for Codex and other AI assistants.

Version 0.1.0

## What it does

This tool runs realistic PM interview practice and coaching across:

- Product design and product sense
- Execution, prioritisation, and metrics
- Strategy and trade-offs
- Behavioural and leadership questions
- Case studies and follow-up probing

It adapts the session to the applicant's target level—Associate PM, PM, Senior PM, or Principal PM—and asks for relevant career context, including a CV or résumé, before personalising the practice.

## Codex installation

Install the skill from this repository using the Codex skill installer, pointing it to:

`skills/product-manager-interview`

The native skill package is in [skills/product-manager-interview](skills/product-manager-interview/).

## Privacy

No personal CVs, résumés, or user profiles are included in this repository. Users should share only the career information they are comfortable providing to their chosen AI assistant and should redact sensitive personal details where appropriate.

## Scope

This is general Product Manager interview preparation. It is not an official hiring rubric or representation of any company's interview process.
