# Kimi Project or Agent setup

For Kimi Projects, paste the contents of `universal-instructions.md` into the Project instructions and upload `knowledge/product-manager-interview-playbook.md` as a knowledge file.

For Kimi Agent mode, use the same text as the custom skill or system prompt, and attach the playbook as a reference file if the interface supports it.

At the beginning of each new candidate's first chat, use this opening:

> Before we start, tell me your target role—APM, PM, SPM, or Principal PM—and upload or paste your CV. I will use both to personalize the interview. You may redact contact details and any information you do not want processed.

Keep each candidate's CV scoped to that candidate's project or chat. Do not place private CVs in a shared project or shared skill.
